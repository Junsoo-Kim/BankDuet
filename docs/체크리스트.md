# 제출 셀프 체크리스트

2026-11-18 로컬 시연 기준이다. 수업 요구사항의 ID를 유지했다. 완료는 아래 범위의 구현과 시험을 뜻하며, 부분은 실계정·외부 공급자 증빙 등 남은 조건이 있음을 뜻한다. 별도 수업 제출 양식은 작업 폴더에서 확인되지 않아 이 표로 정리했다.

## 선택 심화

| ID | 인수 기준 | 판정과 근거 |
|---|---|---|
| F3020 선택 | 반복 호출·계획 외 호출·재계획 초과 진단 | 부분 · 규칙 판정, 정상 시 모델 0회, 이상 시에만 진단, 공급자 실패시 판정 유지와 다음 실행 참조 시험. 이상 원인 진단에 대한 GMS 실응답 미검증 |

금융결제원 계좌 조회는 합성 데이터로 검증했다. 카카오·GMS 인증 실호출은 KB 상담의 영통 지점 검색 1건에서 확인했다. 수업 명세의 SQLite 예시와 달리 은행별 PostgreSQL을 선택했다. 제출처의 대체 허용 여부와 공식 양식은 별도 확인 대상이다. F3021~F3023은 이번에 선택하지 않았다.
